# Прогулка по Лобачевскому («Пятый постулат»)

Интерактивная 3D-среда в гиперболическом пространстве Н. И. Лобачевского. Raymarching в пространстве Минковского R³·¹, модель Кэли — Клейна, отражения групп Кокстера. Без сторонних движков — чистый WebGL2 + GLSL, один файл.

Предназначение двойное: **интерактивная визуализация** для изучения геометрии Лобачевского и **ядро стелс-игры** «Пятый Постулат» (см. [GAME_CONCEPT.md](GAME_CONCEPT.md)).

## Запуск

Ничего собирать не нужно — откройте `index.html` в Chrome / Firefox / Edge / Safari. Требуется WebGL2.

Локальный сервер (опционально):

## Миры (6)

1. **Додекаэдры с прямыми углами** {5,3,4} — 4 комнаты у ребра
2. **Кубы с углом 72°** {4,3,5} — 5 кубов у ребра
3. **Кубы с вершинами на абсолюте** {4,3,6} — 6 кубов, рёбра уходят в бесконечность
4. **Евклидовы кубы** — для сравнения (угол 90°)
5. **Дом на орисферах** — каждый этаж вдвое шире, h = ln 2
6. **Плоскость {5,4}** — прямоугольные пятиугольники + миникарта Кэли — Клейна

## Математика

- Точки — векторы в **R³·¹**, форма ⟨x,y⟩ = x₁y₁+x₂y₂+x₃y₃ − x₀y₀, гиперболоид ⟨x,x⟩ = −1.
- Движения — матрицы из **SO(1,3)**: гиперболические бусты, повороты, параболические сдвиги (орисферы).
- Рендер — **raymarching** с фолдингом в фундаментальную область группы Кокстера.
- Формулы — в панели «Об этом мире» и в курсовой.

## Кампания «Пятый Постулат» (клавиша 7)

Сюжетная стелс-игра в духе *Dishonored*: пролог, пять глав и три концовки. Онлайн: добавьте `#game` к адресу.

| Глава | Геометрия | Суть |
|---|---|---|
| Пролог. Идеальный квадрат | евклидов город (кубы) | обход Чертёжной; зал с суммой углов 359° |
| 1. Архив лишних точек | соты {5,3,4} | Линза Абсолюта и лист 281 |
| 2. Тюрьма-додекаэдр | соты {5,3,4}, камень и железо | побег, вернуть Линзу; Циркулятор Кассель |
| 3. Башня на орисферах | верхнее полупространство, этажи ln 2 | подъём к Сестре Орицикле, зеркало σ |
| 4. Равнина пятиугольников | плоскость {5,4} | межевые камни; Бернхард ждёт там, где не сошёлся «квадрат» |
| 5. Цитадель Прямых Углов | соты {4,3,5}: «прямые» углы по 72° | Врата трёх геометрий (настоящую дверь видно только в Линзе), зал украденных углов, реестр вычеркнутых, Кассель (пощада, если он ни разу не гнался за Верой), диспут и признание Евклида; финал — чертёж на одном из трёх узлов: квадрат (Прямизна), разрыв контуров 5 × 72° (Кривизна), совместимые геометрии в круге Кэли — Клейна (Пятый постулат) |

- **Концовки:** «Прямизна», «Кривизна» и секретная «Пятый постулат» (все доводы в диспуте верны и найдено не меньше 12 лемм из 16). Эпилог учитывает тревоги за всю кампанию.
- **Стражи:** Чертёжники, Тюремщики, Надзиратели орисфер с фонарями, Циркуляторы Равнины, Стражи Цитадели и Кассель с маятником (его нельзя усыпить, он чувствует любую способность рядом). Патруль, подозрение, погоня, поиск; шум, тела, свет, реплики.
- **Способности:** геодезический рывок (ПКМ или B), Линза Абсолюта (V), зеркало σ — отражение-приманка (G), усыпление (F).
- **Леммы:** 16 настоящих теорем с подписями авторов — Евклид, Саккери, Ламберт, Гаусс, Лобачевский, Бойяи, Вахтер, Риман, Бельтрами, Кэли, Клейн, Пуанкаре, Минковский, Кокстер.
- **Портреты:** «бронзированные силуэты» — жанр эпохи Лобачевского; портретная галерея персонажей и геометров (`portraits.js`).
- **Шрифт «Циркуль»** (`font.js`): собственная заголовочная гарнитура, буквы построены отрезками и дугами, с гравированной линией внутри штриха.

## Графика

- **Пост-обработка** (`post.js`): сцена рендерится в HDR-текстуру, дальше — свечение (bloom), живописный фильтр Кувахары (стиль масляной живописи, заодно сглаживает пониженное разрешение рэймарчинга), тушевые контуры по разрыву глубины, тон-маппинг ACES, цветокоррекция «тени — бирюза, света — янтарь», виньетка, зерно.
- **Материалы**: латунные рёбра с гравировкой и патиной, PBR-освещение (GGX), мягкое затенение углов (AO), рельеф через карту высот, витражи со свинцовыми жилками в стеклянных гранях, объёмное свечение ламп в воздухе.
- **Миссия**: стены с обоями, деревянными рамами, латунными валиками и медальонами-розетками (у каждого зала свой цвет); стражи — фигуры Чертёжников (мантия, капюшон, фарфоровая маска с линзой-глазом, латунный циркуль), мягкие тени от них; предметы смоделированы SDF (лупа-Линза, лист с сургучом, кристаллы дефекта, портал Окна).
- **Шрифты**: Oranienbaum (заголовки, петербургская антиква), Old Standard TT (текст и реплики, русская книжная гарнитура XIX века), IBM Plex (цифры). Эмблема нарисована геометрически: прямоугольный пятиугольник {5,4} в диске Пуанкаре. Панели — в латунных рамках.
- Отладка: `index.html?scale=0.3` — фиксированное разрешение сцены.

## Враг (стелс-прототип)

В мирах 1–3 появляется охранник-сфера (один на всё пространство: он живёт в абсолютных координатах R³·¹, а не в фундаментальной области, поэтому не повторяется в каждой комнате): патрулирует, имеет конус зрения 75° в касательном пространстве, проверяет видимость по геодезической через SDF препятствий (рёбра, вершины, лампа). Шкала «тревога» (слева внизу) растёт при обнаружении, сфера краснеет, экран даёт красную виньетку.

## На телефоне и офлайн

- **Сенсорное управление:** левый круг — идти, ведите пальцем по экрану — смотреть, ▲ ▼ — вверх и вниз; кнопки «Рывок», «σ», «Линза», «F», «Бег», «Карта» (и «Присесть» в прологе и главе 4). Подсказку действия в центре экрана можно просто нажать.
- Игра лучше всего выглядит в горизонтальной ориентации и на весь экран (включается сама при старте главы).
- **Установить как приложение:** если игра открыта по адресу `https://…` (например, GitHub Pages), в меню браузера есть «Установить приложение» / «На экран „Домой“». После первого запуска она работает без сети (`sw.js`, `manifest.webmanifest`).
- **Один файл:** `dist/pyatyi-postulat.html` — вся игра в одном файле, собирается командой `python3 tools/build-single.py`.
