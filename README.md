# Прогулка по Лобачевскому («Пятый постулат»)

Интерактивная 3D-среда в гиперболическом пространстве Н. И. Лобачевского. Raymarching в пространстве Минковского R³·¹, модель Кэли — Клейна, отражения групп Кокстера. Без сторонних движков — чистый WebGL2 + GLSL, один файл.

Предназначение двойное: **интерактивная визуализация** для изучения геометрии Лобачевского и **ядро стелс-игры** «Пятый Постулат» (см. [GAME_CONCEPT.md](GAME_CONCEPT.md)).

---

## Запуск

Один файл, ничего собирать не нужно — откройте `index.html` в Chrome / Firefox / Edge / Safari. Требуется WebGL2.

Локальный сервер (опционально):

```bash
python -m http.server
# или
npx serve .
```

## Миры (6)

1. **Додекаэдры с прямыми углами** {5,3,4} — 4 комнаты у ребра
2. **Кубы с углом 72°** {4,3,5} — 5 кубов у ребра
3. **Кубы с вершинами на абсолюте** {4,3,6} — 6 кубов, рёбра уходят в бесконечность
4. **Евклидовы кубы** — для сравнения (угол 90°)
5. **Дом на орисферах** — каждый этаж вдвое шире, h = ln 2
6. **Плоскость {5,4}** — прямоугольные пятиугольники + миникарта Кэли — Клейна

## Математика

- Точки — векторы в **R³·¹**, форма ⟨x,y⟩ = x₁y₁+x₂y₂+x₃y₃ − x₀y₀, гиперболоид ⟨x,x⟩ = −1.
- Движения — матрицы из **SO(1,3)**: гиперболические бусты, повороты, параболические сдвиги (орисферы).
- Рендер — **raymarching** с фолдингом в фундаментальную область группы Кокстера.
- Формулы — в панели «Об этом мире» и в курсовой.

---

## Враг (стелс-прототип)

В мирах 1–3 появляется охранник-сфера: патрулирует, имеет конус зрения 75° в касательном пространстве, проверяет видимость по геодезической через SDF препятствий (рёбра, вершины, лампа). Шкала «тревога» (слева внизу) растёт при обнаружении, сфера краснеет, экран даёт красную виньетку.
